# Source Localization Analysis using Parmigiani CCEP Dataset 

Python analysis of the simultaneous high-density scalp EEG and stereo-EEG
dataset described by Parmigiani et al. (2022).

## Project structure

- `data/raw/`: original BIDS dataset; excluded from Git
- `data/processed/`: generated and preprocessed data
- `notebooks/`: exploratory notebooks
- `scripts/`: reproducible Python scripts
- `outputs/figures/`: generated figures
- `outputs/tables/`: generated tables
- `references/`: external reference code
